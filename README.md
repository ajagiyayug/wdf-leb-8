# Practical 8: MySQL Schema Design, ER Model, PDO Connectivity, and Prepared Statements

## 📌 Overview
Is practical ka main purpose **StudentHub** application ke liye ek well-structured, normalized MySQL database design karna aur usse PHP ke saath securely connect karna hai[cite: 2]. Is practical me database management, schema normalization, aur secure connection techniques ko practically implement kiya gaya hai.

Yeh practical intermediate aur advanced PHP database integration concepts jaise **PHP Data Objects (PDO)**, **Prepared Statements** (SQL Injection protection ke liye), aur **Stored Procedures** ko seekhne aur implement karne ke liye hai.

---

## 🛠️️ Tools & Technologies Used
* **Database Management:** MySQL, phpMyAdmin
* **Backend Programming:** PHP
* **Server Environment:** XAMPP

---

## 🎯 Key Objectives & Learning Outcomes
* **Normalized Database Design:** Students, Events, aur Registrations tables ke bich proper Primary Keys aur Foreign Keys ke saath normalized database schema create karna.
* **Secure Database Connection:** MySQL database ke saath secure error-handled PHP PDO connection establish karna (`db.php`).
* **Prepared Statements:** SQL injection threats se bachne ke liye safe queries prepare aur execute karna.
* **Advanced Extensions:** Database workflows ko optimized rakhne ke liye Stored Procedures ka use karna.

---

## 📁 Submission Deliverables (Post Lab Work)
* **`schema.sql`**: Complete SQL seed data aur schema export.
* **`db.php`**: Secure PDO database connectivity file.
* **Connection Test Screenshot**: Successful database connectivity status ka screenshot.
